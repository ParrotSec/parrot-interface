Parrot Cyberpunk

Super is the Windows or Command key. Reopen this guide with Super+F1 or the panel's ? button.

Get around

Apps opens the application menu. Browse Parrot Security and its nested tool categories; Back returns to the previous level. Use Search or Super+Space to find a program by name. Workspace numbers switch desktops; Ctrl+Alt+Left/Right moves through the four desktops. App icons focus windows; right-click an app icon to close it.

Windows tile automatically. Hold Super and left-drag a window to drop it at a new position in the layout, or right-drag to resize it.

Use the network tray icon to join Wi-Fi. Click the volume indicator for sound settings; scroll over it to adjust volume.

Settings includes Bluetooth, displays, wallpaper and idle timers. It also has a Lock and power entry for locking, suspending, logging out, restarting or shutting down.

Make it yours

Settings → Wallpaper opens ~/.config/hypr/hyprpaper.conf, where you can change the image path and fit mode. Saving restarts Hyprpaper automatically.

Settings → Idle timers opens ~/.config/hypr/hypridle.settings. Timeouts are in seconds; the defaults lock after 10 minutes, turn the display off after 15 minutes and suspend after 30 minutes.

Settings → Desktop configuration opens ~/.config/hypr/local.lua. Examples cover keyboard layout, display scaling and animations. Save with Ctrl+O, then Enter; exit with Ctrl+X. Changes reload automatically.

More applications

Install additional software with Parrot's APT tools, for example sudo apt install PACKAGE.

To install Parrot to disk, open its installer from Apps.
